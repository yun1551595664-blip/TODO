# Issue Ops Design System

The selected Apple-inspired visual is the single source of truth.

- Color: canvas `#FBFBFD`, surface `#FFFFFF`, text `#1D1D1F`, secondary `#6E6E73`, line `#E5E5EA`, primary `#6C63FF`; semantic colors are used only for status.
- Type: system/SF Pro/PingFang stack; body 14px, secondary 12px, section 18px, page title 32px; tabular figures for metrics.
- Spacing: 8px grid (`8/16/24/32/48/64`).
- Radius: controls 10px, cards 14px, floating navigation 22px. Avoid nested cards.
- Shadow: only floating navigation, dialogs and the AI insight surface; `0 12px 36px rgba(30,30,50,.08)`.
- Buttons: 38px height; one primary action per region. Secondary actions remain neutral.
- Tables: 44-48px rows, transparent header, hairline separators, quiet hover state.
- Status: small dot plus text or low-contrast tag. Never use saturated tag walls.
- Cards: independent objects only. Prefer whitespace, typography and rules for hierarchy.
